# SaaS Dashboard

Full-featured SaaS dashboard with authentication, role-based access control, and analytics. Built with Next.js, shadcn/ui, and Supabase.

**Stack:** Nextjs | **Complexity:** complex
**Tags:** `saas`, `dashboard`, `auth`, `rbac`, `analytics`, `supabase`, `shadcn`

## Quick Start

```bash
npm install
npm run dev
```

## Docker

```bash
docker compose up --build
```
